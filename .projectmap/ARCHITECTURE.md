## Overview
ResearchAI is a **dual-host** plugin for Stats/ML researchers whose core output is
**developing new algorithms**: one `skills/` core fronted by two thin wrappers —
Claude Code (`.claude-plugin/`, plugin name `research-assistant`, slash commands) and
Codex (`.codex-plugin/`, plugin name `research-ai`, skill invocations; Codex does not
load `commands/`). It bundles three independently-usable skills —
`literature-explorer` (`/explore`), `algo-brainstorm` (`/algo`), and `paper-writer`
(`/write`) — plus a `research-conductor` autopilot (`/research`) that sequences the
other three from idea to paper. A fifth, **stateless** skill `peer-reviewer`
(`/review`) sits outside the pipeline: it referees *other people's* manuscripts from a
file (no `.research-state`), reusing the venue profiles, prose-hygiene, and council
machinery behind a review-ethics gate. A sixth, `evidence-store`, is not a workflow but
the shared data layer the others call before claiming anything. The four pipeline
skills share control state via `.research-state/<topic-slug>.md`, while canonical
evidence lives in a user-selected external Obsidian vault managed by `evidencectl`. The
plugin is overwhelmingly prompt-driven: behaviour lives in Markdown (per-skill
`SKILL.md`, per-mode files, shared prompts, venue/style profiles); the indexed Python is
the deterministic glue — evidence store, literature retrieval, citation auditing,
figures, static gates, and multi-model council dispatch.

## Entry points
Claude Code entry points are five slash commands (`commands/research.md`,
`commands/explore.md`, `commands/algo.md`, `commands/write.md`,
`commands/review.md`) that load the matching `SKILL.md`; Codex invokes the same skills
directly (`$research-ai:<skill>`). `commands/review.md`
loads the standalone `skills/peer-reviewer/SKILL.md`. `/research` loads `skills/research-conductor/SKILL.md`, a
prompt-only orchestration loop (`routing.md` + `bootstrap.md`, no Python) that
drives the other three. Every documented invocation resolves an absolute
`$PLUGIN_ROOT` from the loaded skill and runs from the user's project cwd — never
`cd "$PLUGIN_ROOT"`, never a bare `python3 script.py` (enforced by
`scripts/check_host_parity.py` and `tests/test_executable_paths.py`). The runnable
Python/shell scripts the skills invoke:
- `shared/evidencectl.py` / `skills/evidence-store/scripts/evidencectl.py` — the evidence-store CLI onto `shared/evidence_core/` (stdlib-only)
- `shared/council.py` — multi-model `--council` panel dispatcher (CLI; stdlib-only)
- `skills/literature-explorer/scripts/search_{arxiv,openalex,semantic_scholar}.py` — retrieval CLIs
- `skills/literature-explorer/scripts/dedupe_rank.py` — deterministic merge/dedup/rank of retrieval JSONL (stdlib-only)
- `skills/paper-writer/scripts/verify_citations.py` — citation auditor CLI
- `skills/paper-writer/scripts/check_tex.py` — static TeX cross-checks: `\cite`↔`.bib`, `\ref`↔`\label`, figures, venue `must_include` (stdlib-only)
- `skills/paper-writer/scripts/check_prose.py` — prose-format lint: `prose_hygiene.md` §F list budget, pseudo-list runs, §A banned phrases, em-dash rate, rhythm warnings (stdlib-only)
- `skills/paper-writer/scripts/check_venues.py` — venue-knowledge consistency: Defaults ↔ prose profiles ↔ `style/` ↔ `check_tex.py` tokens, provenance + staleness (stdlib-only)
- `skills/paper-writer/scripts/build_paper.sh` — LaTeX compile gate + DOCX export (not in `tags`)
- `skills/paper-writer/scripts/figs.py` — figure-style library; also a standalone smoketest
- `skills/peer-reviewer/scripts/scan_injection.py` — injection-pattern scan + two-extractor divergence check (stdlib-only)
- `scripts/check_host_parity.py` — repo maintenance: Codex↔Claude wrapper parity + runtime-path lint (stdlib-only; not skill runtime)

## Conventions
- **Map scope — read this first:** ctags only indexed Python, but the substance of
  this repo is Markdown. Grep `commands/*.md`, `skills/*/SKILL.md`, `skills/*/modes/*.md`,
  `skills/*/checklists/*.md`, and `shared/prompts/*.md` directly — they are **not** in `tags`.
- **Skills are mode-based:** a skill dispatches to one `modes/<name>.md` per invocation
  (e.g. `/algo gap-analysis`, `/write outline`). Add behaviour as a new mode file.
- **Cross-skill/session state** lives in `.research-state/<topic-slug>.md`, per
  `shared/research_state.schema.md` — the handoff between explore → algo → write.
- **Lifecycle gates over stages:** `shared/prompts/research_lifecycle.md` sits above the
  legacy `stage` machine — `research_phase` plus a *validated gate artifact* decides
  whether the pipeline may advance; a stage name is never proof its gate passed. Use the
  phase→gate-key mapping in `research_state.schema.md` verbatim (`tests/test_research_lifecycle.py` enforces it).
- **Evidence grounding:** literature claims follow `shared/prompts/evidence_grounding.md`
  — the external vault is the data plane, `.research-state` the control plane, and
  `refs/<slug>.bib` only a generated view. `verified` requires an inspected locator plus a
  matching passage hash; abstract-only evidence can never be `verified`/`supports`/`contradicts`.
- **Dual-host discipline:** never add `.claude/skills` or `.codex/skills` — that forks the
  core. Keep both manifests and `pyproject.toml` on the same base version, and write every
  documented command with an absolute `$PLUGIN_ROOT` (`uv run --project "$PLUGIN_ROOT"`).
  `scripts/check_host_parity.py` is the gate.
- **Python:** stdlib + a few deps (`httpx`, `tenacity`, `pybtex`; `matplotlib`/`numpy`
  optional via the `figures` extra). Managed by uv (`uv sync`), `package = false`.
  Retrieval/audit scripts use `tenacity` retries against external APIs.
- **MIT-licensed throughout; no copyleft or non-commercial deps** (project is license-sensitive).
- **Anti-sycophancy / anti-hallucination** are baked into the prompts: brainstorm responses
  must surface weaknesses first, and `--council` output is ideation-only — its citations are
  `[VERIFY]`-flagged and must pass the citation audit before entering research-state.
- **Economy delegation:** `/research --economy` lets the conductor run the token-heavy,
  judgment-light stages (explore, full-draft, revision, citation-audit — marked `✓` in
  `skills/research-conductor/routing.md`) in a cheaper implementer subagent, with a
  DONE/CONSULT protocol and a non-skippable acceptance gate in
  `shared/prompts/model_dispatch.md`. Grills, verdicts, and review never delegate.
- **Model-robustness:** every mode file ends with an `## Exit checklist` and all skills obey
  `shared/prompts/execution_discipline.md` (two-pass emission, declared skips, scripts-over-
  recall) so quality holds on smaller Claude models. Keep new mechanical steps in
  deterministic scripts (`dedupe_rank.py`, `check_tex.py`, `scan_injection.py` pattern), and
  give any new mode an Exit checklist. The discipline's **Strong-model tier** (Mythos-class)
  relaxes only the two scaffolding rules (two-pass emission, emitted re-anchor); script gates,
  Exit checklists, and honesty rules never relax, and `--economy` implementers always run
  standard tier.
